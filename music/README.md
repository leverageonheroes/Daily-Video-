# Music beds

Put royalty-free tracks here, named after the mood in each script. Download them from
**YouTube Studio → Audio Library** (safe from Content ID claims, which would block Shorts over 60 s).

Missing files are fine: the pipeline falls back to `default.mp3`, and to no music if that's missing too.

```
comedic-pizzicato.mp3      dramatic-organ.mp3     epic-choir.mp3          lofi-chill.mp3
ominous-drone.mp3          romantic-violin.mp3    sitcom-pluck.mp3        spy-heist.mp3
suspense-sting.mp3         telenovela-strings.mp3 tense-comedic-strings.mp3 tragic-piano.mp3
triumphant-brass-sting.mp3 upbeat-ukulele.mp3     villain-organ.mp3       western-standoff.mp3
default.mp3

Drizzle & Pudge (kids):
playful-xylophone.mp3  bouncy-ukulele.mp3  gentle-music-box.mp3  silly-tuba.mp3  magic-twinkle.mp3  happy-whistle.mp3
```
mp3, m4a, wav or ogg all work. Tracks loop automatically and sit at 12% volume under the dialogue.
